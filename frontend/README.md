# Frontend – AI Tools Hub (Next.js)

Next.js 15 + React 19 + TypeScript + Tailwind CSS 4. Работи в Docker на http://localhost:8200.

Инструкциите за инсталация, ролите и API-то са в главния [README.md](../README.md).
Архитектурата и правилата за разработка са в [CLAUDE.md](../CLAUDE.md).

```bash
docker compose logs -f frontend      # логове и грешки при компилация
docker compose exec frontend npm run lint
```
